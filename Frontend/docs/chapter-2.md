## Core Concepts

Spec-Kit Plus provides a structured approach to AI-driven development that ensures quality, consistency, and reproducibility. This chapter explores the five core phases that make up the workflow.

### The Five Phases of Spec-Kit Plus

The Spec-Kit Plus workflow consists of five distinct phases:

1. **/sp.constitution**: Establishing rules and quality standards
2. **/sp.specify**: Defining scope and requirements
3. **/sp.plan**: Creating system architecture and design
4. **/sp.tasks**: Breaking down implementation into actionable tasks
5. **/sp.implement**: Executing the development and deployment

### Why Spec-Driven Development Matters

Spec-driven development ensures that all stakeholders have a clear understanding of the project before implementation begins. This approach reduces the risk of scope creep and ensures that the final product meets the original requirements.

## Hands-on Steps

In this section, we'll walk through each phase of the Spec-Kit Plus workflow.

1. **Creating a constitution**: Define project principles and standards
2. **Specifying requirements**: Document user needs and functional requirements
3. **Planning architecture**: Design the technical approach
4. **Breaking down tasks**: Create actionable implementation steps
5. **Implementing the solution**: Execute the development plan

## Commands

```bash
# Run the constitution phase
/sp.constitution "Project Name and Principles"

# Run the specify phase
/sp.specify "Project Requirements and Scope"

# Run the plan phase
/sp.plan

# Run the tasks phase
/sp.tasks

# Run the implement phase
/sp.implement
```
